# notes-mcp 设计草案

目标：把我本地的 Markdown 笔记暴露给 AI 助手，**只读**。

## 四个工具

| 名称 | 参数 | 返回 |
|---|---|---|
| search_notes | query, limit | 命中片段，不是全文 |
| read_note | path | 单篇全文，超限截断 |
| list_recent | days | 最近改动的清单 |
| notes_stats | 无 | 总数 / 字数 / 标签分布 |

## 三条硬约束

### 1. 路径安全

path 来自模型，是不可信输入。必须 `Path.resolve()` 之后再判断是否仍在根目录内，
否则符号链接可以绕过字符串检查。绝对路径、`..`、NUL 字节一律拒绝。

### 2. 上下文预算

search_notes 绝不能返回整篇。每篇最多 3 个片段，每段前后 2 行，
总预算 8000 字符。超了要明说"已截断"。

### 3. 结构化错误

失败时返回可读说明（"路径越界，只允许根目录内的相对路径"），
而不是抛裸异常。模型需要靠这句话自我纠正。
